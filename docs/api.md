## `<gpu>`

GPU compute and rendering over WebGPU (wgpu-native).

`<gpu/core>` opens the device and runs compute kernels; `<gpu/render>` draws
into textures and window surfaces. The raw WebGPU API is in `<gpu/raw>`.


## `<gpu/async>`

Waiting for the GPU from async code. The device is polled from
the event loop every millisecond until the work is done, so other tasks run
meanwhile. In a browser each poll also lets the browser run for a moment, since
the callbacks come from its event loop.

```eskiu
int r = await gpu.wait_async(lp);
Result<int, string> got = await v.read_async(lp, out, bytes);
```

### Gpu_wait_async

```eskiu
async int Gpu_wait_async(*Gpu self, EventLoop* lp)
```

Completes with 0 once the work submitted so far has finished, -1 when the
queue reports an error or a minute passes.

### GpuBuffer_read_async

```eskiu
async Result<int, string> GpuBuffer_read_async(*GpuBuffer self, EventLoop* lp, *void out, uint64 bytes)
```

read() for async code: copies the first bytes bytes of the buffer to out.


## `<gpu/core>`

Devices, buffers and compute kernels (imported by `<gpu>`).

gpu_open() picks an adapter and a device. Every fallible call returns a
Result whose error is a message from the WebGPU validation layer; the message
lives in a buffer that the next error reuses, so copy it to keep it.
Each object has a release method, meant to be paired with defer:

```eskiu
Gpu gpu = gpu_open()?;
defer gpu.release();
GpuBuffer v = gpu.storage(data, bytes)?;
defer v.release();
```

The raw WebGPU API is in `<gpu/raw>` for anything this layer does not cover.

In a browser (wasm32-unknown-emscripten) the API is the same: each wait for the
GPU suspends the program until the browser's promise settles, which needs a build
with --link-arg=-sJSPI or --link-arg=-sASYNCIFY (docs/web.md). Without WebGPU the
device renders through WebGL2 and has no compute.

### Gpu

```eskiu
struct Gpu {
    WGPUInstance instance;
    WGPUAdapter adapter;
    WGPUDevice device;
    WGPUQueue queue;
    *_GpuState state;
    bool f16;
    bool subgroups;
    uint64 max_buffer;
    uint32 subgroup_min;
    uint32 subgroup_max;
    bool depth32_stencil8;
    bool float32_filterable;
    bool bc;
    bool etc2;
    bool astc;
    bool webgl2;
}
```

f16 and subgroups say whether shaders may use f16 values and subgroup
operations; subgroup_min and subgroup_max bound the subgroup size (they
vary by GPU: 32 on Apple and NVIDIA, 64 on some AMD, 4 to 64 elsewhere;
Metal does not report them and Apple GPUs use 32);
max_buffer is the largest buffer the device allows; depth32_stencil8 says
whether textures may be Depth32FloatStencil8 (Depth24PlusStencil8 always can).
float32_filterable says whether R32Float, RG32Float and RGBA32Float textures
may be sampled with linear filtering; bc, etc2 and astc whether textures may
be in those block-compressed formats (BC on desktop GPUs, ETC2 and ASTC on
phones and Apple Silicon). gpu_open turns on each one the adapter has.
webgl2 says the device is the WebGL2 backend, which a browser without
WebGPU gets (docs/web.md): rendering only, no compute or storage buffers.

### GpuBuffer

```eskiu
struct GpuBuffer {
    Gpu gpu;
    WGPUBuffer handle;
    uint64 size;
}
```

A buffer in GPU memory: handle is the WebGPU buffer and size its length in bytes. It
keeps a copy of the Gpu that made it, so it must be released before that Gpu is.

### GpuKernel

```eskiu
struct GpuKernel {
    Gpu gpu;
    WGPUShaderModule module;
    WGPUComputePipeline pipeline;
    WGPUBindGroupLayout layout;
    List<WGPUBindGroupEntry> entries;
}
```

A compute pipeline made by Gpu_kernel: the shader module, the pipeline, the layout of
its bind group 0 and the buffers bound so far with bind(). It keeps a copy of the Gpu
that made it.

### gpu_str

```eskiu

```

A WebGPU string view over s, without copying it; null gives an empty view. For calls
into `<gpu/raw>`.

### gpu_open

```eskiu
Result<Gpu, string> gpu_open()
```

Opens the high-performance adapter and a device with the adapter's full limits and every
optional feature listed on Gpu that it has. Fails with "no WebGPU instance", "no GPU
adapter" or "no GPU device" and the driver's message; in a browser also with "no
WebGPU in this browser". A browser whose WebGPU is missing or gives no adapter gets the
WebGL2 backend, with Gpu.webgl2 set (docs/web.md).

### Gpu_release

```eskiu

```

Releases the queue, device, adapter and instance and zeroes the Gpu. Release every
object made from it first.

### Gpu_name

```eskiu

```

The adapter's name, as the driver reports it, appended to out.

### Gpu_wait

```eskiu
void Gpu_wait(*Gpu self)
```

Blocks until the work submitted so far has finished.

### Gpu_buffer

```eskiu

```

A buffer of size bytes with the given WGPUBufferUsage flags, its contents zero. Fails

### Gpu_storage


A storage buffer holding a copy of bytes bytes at data (data may be null for

### GpuBuffer_write

```eskiu

```

Copies bytes bytes from data into the buffer at byte offset offset. The copy is queued:

submitted work. offset and bytes must be multiples of 4.

### GpuBuffer_read

```eskiu
Result<int, string> GpuBuffer_read(*GpuBuffer self, *void out, uint64 bytes)
```

Copies the first bytes bytes of the buffer to out, after the work submitted

### GpuBuffer_read_mapped

```eskiu

```

Maps a MapRead buffer and copies its first bytes bytes to out.

### GpuBuffer_release


Releases the buffer; a second call does nothing.

### Gpu_kernel

```eskiu

```

A compute kernel: the function entry of the WGSL source, with the layout
of its bind group 0 taken from the shader.

### GpuKernel_bind

```eskiu

```

Binds the whole of b to @binding(binding) of group 0, for the next dispatches.

### GpuKernel_dispatch

```eskiu
Result<int, string> GpuKernel_dispatch(*GpuKernel self, uint32 x, uint32 y, uint32 z)
```

Runs x * y * z workgroups. The work runs on the GPU after the call returns;
read() and wait() wait for it.

### GpuKernel_release

```eskiu
void GpuKernel_release(*GpuKernel self)
```

Releases the pipeline, its layout and shader module, and the list of bindings (not the
bound buffers).


## `<gpu/gguf>`

GGUF model files (the llama.cpp format): metadata, tensors, and
dequantization of the common block formats.

```eskiu
Gguf f = gguf_load("llama-2-7b.Q4_0.gguf")?;
defer f.free();
int64 dim = f.int("llama.embedding_length", 0);
GgufTensor* wq = f.tensor("blk.0.attn_q.weight");
```

The file is read into memory once; tensors point into it. dequantize()
turns any supported type into floats: F32, F16, BF16, Q4_0, Q4_1, Q5_0,
Q5_1, Q8_0, Q2_K, Q3_K, Q4_K, Q5_K and Q6_K.

### GGML_F32, GGML_F16, GGML_Q4_0, GGML_Q4_1, GGML_Q5_0, GGML_Q5_1, GGML_Q8_0, GGML_Q2_K, GGML_Q3_K, GGML_Q4_K, GGML_Q5_K, GGML_Q6_K, GGML_BF16

```eskiu
const int GGML_F32 = 0;
const int GGML_F16 = 1;
const int GGML_Q4_0 = 2;
const int GGML_Q4_1 = 3;
const int GGML_Q5_0 = 6;
const int GGML_Q5_1 = 7;
const int GGML_Q8_0 = 8;
const int GGML_Q2_K = 10;
const int GGML_Q3_K = 11;
const int GGML_Q4_K = 12;
const int GGML_Q5_K = 13;
```

Tensor types (GgufTensor.type), with ggml's numbering. The _K types are the k-quant
formats in blocks of 256 values; the others hold 32 values per block, except F32, F16
and BF16.

## `<gpu/gltf>`

GlTF 2.0 models (.gltf with external or embedded buffers, and .glb).
It has no GPU dependency: it turns the file into plain arrays that
`<gpu/model>` uploads, or that a tool can inspect.

```eskiu
Gltf m = gltf_load("helmet.glb")?;
defer m.free();
for (i in 0..m.meshes.size) { ... m.meshes.data[i].primitives ... }
```

Every vertex attribute is read into floats whatever its stored type
(normalized integers included, as KHR_mesh_quantization stores them), and
indices into uint32; triangle strips and fans become lists. Images are kept
encoded (PNG or JPEG bytes); `<gpu/image>` decodes them. Morph targets are
read into each primitive (target_positions, target_normals and
target_tangents: the deltas of target t for vertex v at (t * vertex_count +
v) * 3); a node's weights start from its own "weights" or its mesh's, and
Gltf_animate moves them. Files that require Draco or meshopt compression are
rejected.

### GLTF_OPAQUE, GLTF_MASK, GLTF_BLEND

```eskiu
const int GLTF_OPAQUE = 0;
const int GLTF_MASK = 1;
const int GLTF_BLEND = 2;
```

Alpha modes (GltfMaterial.alpha_mode): opaque, cut out below alpha_cutoff, or blended.

### GLTF_TRANSLATION, GLTF_ROTATION, GLTF_SCALE, GLTF_WEIGHTS, GLTF_VISIBLE, GLTF_BASE_COLOR, GLTF_EMISSIVE, GLTF_METALLIC, GLTF_ROUGHNESS, GLTF_ALPHA_CUTOFF, GLTF_TEX_OFFSET, GLTF_TEX_ROTATION, GLTF_TEX_SCALE

```eskiu
const int GLTF_TRANSLATION = 0;
const int GLTF_ROTATION = 1;
const int GLTF_SCALE = 2;
const int GLTF_WEIGHTS = 3;
const int GLTF_VISIBLE = 4;
const int GLTF_BASE_COLOR = 5;
const int GLTF_EMISSIVE = 6;
const int GLTF_METALLIC = 7;
const int GLTF_ROUGHNESS = 8;
const int GLTF_ALPHA_CUTOFF = 9;
const int GLTF_TEX_OFFSET = 10;
const int GLTF_TEX_ROTATION = 11;
const int GLTF_TEX_SCALE = 12;
```

What an animation channel moves (GltfAnimChannel.path): a node's translation, rotation,
scale or morph target weights.

### GLTF_LINEAR, GLTF_STEP, GLTF_CUBIC

```eskiu
const int GLTF_LINEAR = 0;
const int GLTF_STEP = 1;
const int GLTF_CUBIC = 2;
```

Key interpolation (GltfAnimSampler.interpolation): linear (rotations along the sphere),
step (hold each key) or cubic spline.

### GLTF_POINTS, GLTF_LINES, GLTF_TRIANGLES

```eskiu
const int GLTF_POINTS = 0;
const int GLTF_LINES = 1;
const int GLTF_TRIANGLES = 4;
```

Primitive modes, as glTF numbers them. Strips and fans are converted to
GLTF_TRIANGLES on load.

### GltfPrimitive

```eskiu
struct GltfPrimitive {
    int mode;
    uint32 vertex_count;
    *float positions;
    *float normals;
    *float uvs;
    *float uvs1;
    *float tangents;
    *float colors;
    *uint32 joints;
    *float weights;
    uint32 index_count;
    *uint32 indices;
    int material;
    Vec3 min;
    Vec3 max;
    int target_count;
    *float target_positions;
    *float target_normals;

```

target_count morph targets: target_positions, target_normals and
target_tangents hold target_count * vertex_count * 3 floats each (the delta
of target t for vertex v at (t * vertex_count + v) * 3), or are null when no

### GltfMesh

```eskiu
struct GltfMesh {
    String name;
    List<GltfPrimitive> primitives;
    List<float> weights;
}
```

weights are the default morph target weights (one per target; zero when
the file gives none).

### GltfTextureRef

```eskiu
struct GltfTextureRef {
    int texture;
    int texcoord;
    float scale;
    bool has_transform;
    Vec2 offset;
    float rotation;
    Vec2 tscale;
}
```

A material's use of a texture: texture is an index into Gltf.textures, or -1. With
has_transform (KHR_texture_transform) its coordinates are scaled by tscale, turned by
rotation (radians) and moved by offset before sampling; texcoord is then the extension's
texCoord when it gives one.

### GltfMaterial

```eskiu
struct GltfMaterial {
    String name;
    Vec4 base_color;
    GltfTextureRef base_color_texture;
    float metallic;
    float roughness;
    GltfTextureRef metallic_roughness_texture;
    GltfTextureRef normal_texture;
    GltfTextureRef occlusion_texture;
    GltfTextureRef emissive_texture;
    Vec3 emissive;
    int alpha_mode;
    float alpha_cutoff;
    bool double_sided;
    bool unlit;
    float emissive_strength;
}
```

A metallic-roughness material, with the glTF defaults for what the file leaves out:
base_color (linear RGBA) 1, metallic and roughness 1, emissive 0 (already multiplied by
KHR_materials_emissive_strength), alpha_mode GLTF_OPAQUE, alpha_cutoff 0.5. The factors
multiply their textures; the metallic-roughness texture holds roughness in G and
metallic in B, and a texture reference's scale is the normal scale or the occlusion
strength. unlit is set by KHR_materials_unlit.

### GltfTexture

```eskiu
struct GltfTexture {
    int image;
    int sampler;
}
```

A texture: image is an index into Gltf.images and sampler into Gltf.samplers, each -1
when missing or out of range (a KHR_texture_basisu or EXT_texture_webp source counts as
the image).

### GltfImage

```eskiu
struct GltfImage {
    String name;
    String mime;
    *uint8 data;
    uint64 len;
    bool owned;
}
```

An image's encoded bytes and MIME type ("image/png", "image/jpeg").

### GltfSampler

```eskiu
struct GltfSampler {
    int mag_filter;
    int min_filter;
    int wrap_s;
    int wrap_t;
}
```

Filters and wraps with glTF's (OpenGL's) numbers: 9728 nearest, 9729

### GltfNode

```eskiu
struct GltfNode {
    String name;
    int mesh;
    int skin;
    int parent;
    List<int> children;
    Vec3 translation;
    Quat rotation;
    Vec3 scale;
    bool has_matrix;
    Mat4 matrix;
    List<float> weights;
    bool hidden;
}
```

A scene node. mesh and skin are indices into Gltf.meshes and Gltf.skins, or -1; parent
is the parent node or -1 for a root; children are node indices. The local transform is
matrix when has_matrix (column-major) else translation, rotation and scale; Gltf_animate
writes the latter and clears has_matrix. weights are the node's current morph target
weights, one per target of its mesh.

### GltfSkin

```eskiu
struct GltfSkin {
    String name;
    List<int> joints;
    *float inverse_bind;
    int skeleton;
}
```

A skin: joints are node indices, inverse_bind holds one column-major 4x4 matrix (16
floats) per joint (identity when the file has none), and skeleton is the root joint node
or -1.

### GltfAnimChannel

```eskiu
struct GltfAnimChannel {
    int node;
    int path;
    int sampler;
    int material;
    int slot;
}
```

One animated property: node is the node index, path one of GLTF_TRANSLATION,
GLTF_ROTATION, GLTF_SCALE and GLTF_WEIGHTS, and sampler an index into the animation's
samplers. A KHR_animation_pointer channel may instead drive a node's visibility
(GLTF_VISIBLE) or a property of material `material` (GLTF_BASE_COLOR, GLTF_EMISSIVE,
GLTF_METALLIC, GLTF_ROUGHNESS, GLTF_ALPHA_CUTOFF, or GLTF_TEX_OFFSET, GLTF_TEX_ROTATION
and GLTF_TEX_SCALE of texture `slot`: 0 base color, 1 metallic-roughness, 2 normal,
3 occlusion, 4 emissive). Channels with a bad index or an unknown path or pointer are
dropped on load.

### GltfAnimSampler

```eskiu
struct GltfAnimSampler {
    uint32 count;
    *float times;
    *float values;
    int width;
    int interpolation;
    uint32 value_count;
}
```

Key times and values; width is the floats per value (3 or 4, 1 for morph
weights, which hold one value per target for each key). A cubic spline
stores in-tangent, value and out-tangent for each key. value_count is the
number of values (of width floats) in values.

### GltfAnimation

```eskiu
struct GltfAnimation {
    String name;
    List<GltfAnimChannel> channels;
    List<GltfAnimSampler> samplers;
    float duration;
}
```

An animation: its channels, the samplers they use, and duration, the last key time in
seconds over all samplers.

### Gltf

```eskiu
struct Gltf {
    List<GltfMesh> meshes;
    List<GltfMaterial> materials;
    List<GltfTexture> textures;
    List<GltfImage> images;
    List<GltfSampler> samplers;
    List<GltfNode> nodes;
    List<GltfSkin> skins;
```

A loaded glTF model. Every index field refers to these lists; roots are the root nodes

### gltf_parse

Parses a .gltf (JSON) or .glb file held in memory. External buffers and

## `<gpu/ibl>`

Image-based lighting from an environment map (`<gpu/ibl>`).

Gpu_ibl turns an equirectangular (latitude-longitude) HDR image into the
textures a physically based shader lights with: the environment as a cube
map, its diffuse irradiance, its specular reflection prefiltered for each
roughness (one per mip level, GGX importance sampling) and the split-sum
BRDF table. Everything is made on the GPU with render passes into the cube
faces and mip levels (no compute shaders), so it runs wherever rendering
does.

```eskiu
HdrBitmap sky = hdr_load("sky.hdr")?;
defer sky.free();
GpuIbl ibl = gpu.ibl(&sky, null)?;
defer ibl.release();
model.set_ibl(&ibl);      // <gpu/model>
```

Shading with it (what `<gpu/model>` does):

```eskiu
diffuse  = irradiance(n) * base * (1 - metallic) * (1 - F)
specular = specular(reflect(-v, n), lod = roughness * (mips - 1)) * (F0 * lut.r + lut.g)
```

where lut = brdf(NdotV, roughness).


The lighting textures Gpu_ibl makes, all RGBA16Float cube maps except brdf: environment

## `<gpu/inflate>`

Zlib and raw DEFLATE decompression (RFC 1950, RFC 1951).

The output size must be known up front (PNG computes it from the header):
the caller passes a buffer and its capacity, and a stream that would write
past it is an error. Every read of the input is bounds checked; reading past
the end feeds zero bits and is reported as a truncated stream. Huffman codes
are decoded through a 9-bit lookup table with a canonical-code fallback for
the longer ones, the scheme used by stb_image and zlib.

```eskiu
Result<uint64, string> r = inflate_zlib(src, src_len, dst, dst_cap);
uint64 written = r?;
```

### inflate_zlib


Inflates a zlib stream (2-byte header, DEFLATE data, Adler-32 not checked)
into dst, which holds cap bytes. Returns the number of bytes written.

### inflate_raw

```eskiu

```

Inflates raw DEFLATE data with no header.


## `<gpu/jpeg>`

JPEG decoding to RGBA8 (imported by `<gpu/image>`).

Supports baseline and extended sequential Huffman JPEGs and progressive
ones, 8-bit precision, grayscale, YCbCr and RGB (Adobe transform 0 or
component ids 'R' 'G' 'B'), any sampling factors from 1 to 4 that divide the
largest one, restart markers and any number of DHT/DQT segments. Arithmetic
coding, lossless and hierarchical frames, 12-bit samples and CMYK are
rejected. The EXIF orientation (APP1 tag 0x0112) is read, and applied when
asked (ImageOptions.orient); jpeg_orientation reads it alone. Images of more
than ImageOptions.max_pixels pixels (IMAGE_MAX_PIXELS by default) are
rejected before anything is allocated for them.

The pipeline follows libjpeg: the accurate integer IDCT (jidctint), "fancy"
triangle-filter chroma upsampling for 2x1, 1x2 and 2x2 subsampling (pixel
replication otherwise), and the same fixed-point YCbCr to RGB conversion, so
the output stays within a unit or two of djpeg's. The entropy decoder follows
stb_image: a 9-bit Huffman lookup table and a bit buffer that feeds zeros
once a marker or the end of the data is reached. A file that ends before EOI
is reported as truncated.

```eskiu
Result<Bitmap, string> r = jpeg_decode(bytes, len);
```

### jpeg_orientation

```eskiu
int jpeg_orientation(*uint8 data, uint64 len)
```

The EXIF orientation of a JPEG held in memory, from the APP1 segments before
its first scan: 1 (as stored) to 8, as the TIFF tag 0x0112 numbers them
(2 mirrored, 3 turned half a turn, 4 flipped, 5 transposed, 6 to be turned a
quarter clockwise, 7 transversed, 8 a quarter counterclockwise). 1 when it
has none or is not a JPEG.

### jpeg_decode

```eskiu
Result<Bitmap, string> jpeg_decode(*uint8 data, uint64 len)
```

Decodes a JPEG held in memory. The pixels are RGBA8 with alpha 255.

### jpeg_decode_with

```eskiu

```

orient to turn the image upright by its EXIF orientation.

## `<gpu/model>`

Drawing glTF models with physically based shading.

```eskiu
Gltf data = gltf_load("helmet.glb")?;
defer data.free();
GpuModel model = gpu.model(&data, surface.format)?;
defer model.release();
...each frame:
data.animate(0, seconds);                 // optional
model.update(mat4_identity());
GpuPass pass = gpu.pass(frame.view, clear, &depth);
model.draw(&pass, &camera);
pass.end()?;
```

The shading is glTF's metallic-roughness model with base color, metallic-
roughness, normal, occlusion and emissive textures, vertex colors, alpha
mask and blend, double-sided materials, KHR_materials_unlit and skinning,
lit by one directional light (GpuModel.light) and a hemisphere ambient term,
or by an environment (GpuModel_set_ibl, `<gpu/ibl>`) instead of that term.
Morph targets are applied on the GPU with the node weights update() reads
(or GpuModel_set_weights), before skinning. Shadows from the light are
opt-in: GpuModel_enable_shadows, then render_shadows each frame before the
pass that draws the model.
The Gltf must outlive the model: update() reads its node poses. A model is
drawn once per pass (its uniforms hold one pose and one camera). OBJ files
load into the same Gltf (obj_load, or model_load for either kind).

### GpuCamera

```eskiu

    Mat4 view;
    Mat4 proj;
    Vec3 eye;
}
```

A camera: view and proj are the view and projection matrices (WebGPU clip space) and eye
is the camera's position in world space, which the specular shading needs. gpu_camera
and GpuModel_camera make one.

### GpuLight

```eskiu
struct GpuLight {
    Vec3 direction;
    Vec3 color;
    float intensity;
    Vec3 ambient;
}
```

direction points from the light toward the scene; ambient is the sky color
of the hemisphere term (the ground gets a third of it).

```eskiu
    List<_GpuPrim> prims;

    List<_GpuDraw> draws;

    GpuShadowOptions shadow;
    GpuTexture shadow_map;
    GpuPipeline shadow_pipeline;
    GpuSampler shadow_sampler;
    Mat4 light_view_proj;
}
```

A glTF model on the GPU, made by Gpu_model. data is the Gltf it draws (not owned). light
is the directional light and ambient term; transform is the model matrix update() was
last given. encode_srgb says the shader writes sRGB values itself because the target
format is not an sRGB one. ibl is the environment set with GpuModel_set_ibl or null.
shadows, shadow and the shadow_ fields are the state GpuModel_enable_shadows sets up,
with light_view_proj the light's matrix of the last render_shadows. world holds each
node's world matrix from the last update(). The other fields are the model's pipelines,
textures, samplers, buffers and draw list.

### GpuShadowOptions

```eskiu
struct GpuShadowOptions {
    uint32 size;
    float bias;
    float normal_bias;
    float slope_bias;
    float radius;
    Vec3 center;
}
```

Shadows from GpuModel.light (GpuModel_enable_shadows). Each 0 picks the
default:
- size: the shadow map's width and height in texels (2048).
- bias: subtracted from a point's depth from the light before the test, in
  the light box's depth units (0 to 1 from its near to its far side): 0.002.
- normal_bias: how far each point moves along its normal before the test,
  in shadow map texels (1.5).
- slope_bias: the shadow pipeline's depth bias slope scale (1.0).
- radius and center: the box the light sees, a cube of half-size radius
  around center; radius 0 fits the model's bounds (with its transform) at
  each render_shadows.

## `<gpu/nn>`

Neural network building blocks on the GPU.

A program is a list of kernel dispatches recorded once and replayed as one
compute pass: the bind groups are made when an operation is recorded, and
what changes from one run to the next (a token, a position) comes from the
program's step values, written before each run. This is what makes a
transformer step cheap: no allocation, no waiting between kernels.

```eskiu
NnProgram p = gpu.nn_program()?;
NnTensor x = gpu.nn_tensor(dim)?;
p.rmsnorm(&xb, &x, &weight, dim);
p.matvec(&q, &wq, &xb, dim, dim);
...
p.set_step(token, pos);
p.run()?;
```

Tensors are flat buffers of floats (f32), or of f16 for weights stored with
nn_tensor_f16. Subgroup operations are used when the device has them.

### NnTensor

```eskiu
struct NnTensor {
    GpuBuffer buf;
    uint64 count;
    bool f16;
    int kind;
    GpuBuffer scales;
}
```

kind is NN_F32, NN_F16, NN_Q8_0 or NN_Q4_0. A quantized tensor keeps one
f32 scale per block of 32 values in scales and the packed values in buf.

### NN_F32, NN_F16, NN_Q8_0, NN_Q4_0

```eskiu
const int NN_F32 = 0;
const int NN_F16 = 1;
const int NN_Q8_0 = 2;
const int NN_Q4_0 = 3;
```

Tensor kinds (NnTensor.kind): 32-bit floats, 16-bit floats, and the GGUF Q8_0 and Q4_0
block formats (32 values per block with an f32 scale each).

### NnProgram

```eskiu
struct NnProgram {
    Gpu gpu;
    List<_NnOp> ops;
    List<_NnPipe> pipes;
    List<GpuBuffer> params;
    GpuBuffer step;
    uint32[4] step_values;
    float eps;
    float rope_base;
    bool rope_neox;
}
```

A recorded list of dispatches, made by Gpu_nn_program. step holds the step values set
with set_step(); eps (1e-5) is the epsilon of rmsnorm, rope_base (10000) the RoPE
frequency base and rope_neox the RoPE layout, each read when an operation is recorded,
so set them before recording. The other fields hold the dispatches, their pipelines (one
per kernel kind, shared) and their parameter buffers. It keeps a copy of the Gpu that
made it.

### Gpu_nn_tensor

```eskiu

```

An f32 tensor of count values in a storage buffer, zeroed (with 16 bytes of padding at
the end).

### Gpu_nn_upload

```eskiu

```

A tensor filled from count floats at data.

### Gpu_nn_upload_f16

```eskiu

```

A tensor of count values stored as f16 (half the memory and bandwidth of
f32), converted from count floats at data. Needs Gpu.f16.

### Gpu_nn_upload_q8_0

```eskiu

```

A tensor of count values from GGML Q8_0 blocks at raw (34 bytes per 32

### Gpu_nn_upload_q4_0

```eskiu

```

A tensor of count values from GGML Q4_0 blocks at raw (18 bytes per 32

```eskiu

```

The values the kernels read as step.a and step.b on the next run (a token

### NnProgram_run

```eskiu

```

Runs every recorded dispatch in order, as one compute pass.

### NnProgram_release

### NnProgram_embed

```eskiu
void NnProgram_embed(*NnProgram self, *NnTensor out, *NnTensor table, uint32 n)
```

out[i] = table[step.a * n + i] for i < n (a token's embedding row).

### NnProgram_rmsnorm

```eskiu
void NnProgram_rmsnorm(*NnProgram self, *NnTensor out, *NnTensor x, *NnTensor weight, uint32 n)
```

out = weight * x / sqrt(mean(x^2) + eps), over n values (out may be x);
eps is the program's (1e-5 unless changed).

### NnProgram_matvec_at

```eskiu
void NnProgram_matvec_at(*NnProgram self, *NnTensor out, uint32 out_offset, uint32 out_pos_stride, *NnTensor w, uint64 w_offset, *NnTensor x, uint32 rows, uint32 cols)
```

out[out_offset + step.b * out_pos_stride + r] = sum_c w[w_offset + r * cols + c] * x[c]
for r < rows: a matrix (row-major, rows x cols) times a vector. One
subgroup (or a 32-thread slice of the workgroup) per row.

### NnProgram_matvec

```eskiu
void NnProgram_matvec(*NnProgram self, *NnTensor out, *NnTensor w, *NnTensor x, uint32 rows, uint32 cols)
```

out = w (rows x cols, row-major) * x.

### NnProgram_rope

```eskiu
void NnProgram_rope(*NnProgram self, *NnTensor q, *NnTensor k, uint32 k_offset, uint32 k_pos_stride, uint32 dim, uint32 kv_dim, uint32 head_size)
```

Rotary position embedding at position step.b on q (dim values) and on the
key k written at k_offset + step.b * k_pos_stride (kv_dim values). The
pairs are adjacent values (Meta's and llama.cpp's layout), or the two halves
of each head when the program's rope_neox is set (Hugging Face's layout).

### NnProgram_attention

```eskiu
void NnProgram_attention(*NnProgram self, *NnTensor out, *NnTensor q, *NnTensor kcache, *NnTensor vcache, uint32 cache_offset, uint32 n_heads, uint32 n_kv_heads, uint32 head_size, uint32 seq_len)
```

Causal multi-head attention for the query at position step.b over the
cached keys and values of positions 0..step.b (rows of kv_dim floats from
cache_offset), with grouped-query heads: out (dim) gets each head's
weighted sum. One workgroup per head.

### NnProgram_add

```eskiu
void NnProgram_add(*NnProgram self, *NnTensor x, *NnTensor y, uint32 n)
```

x += y over n values.

### NnProgram_silu_mul

```eskiu
void NnProgram_silu_mul(*NnProgram self, *NnTensor a, *NnTensor b, uint32 n)
```

a = silu(a) * b over n values (SwiGLU).

### NnProgram_argmax

```eskiu
void NnProgram_argmax(*NnProgram self, *NnTensor out, *NnTensor x, uint32 n)
```

out[0] = the index of the largest of the n values in x (as a float bit
pattern of a u32; read it with NnTensor_read and reinterpret).


## `<gpu/obj>`

Wavefront OBJ models with their MTL materials and textures.

obj_load returns the same Gltf that gltf_load does, so `<gpu/model>` draws an
OBJ file as it draws a glTF one:

```eskiu
Gltf data = obj_load("chair.obj")?;
defer data.free();
GpuModel model = gpu.model(&data, surface.format)?;
```

Each `o` object becomes a mesh with one node, and each material used in it a
primitive. Faces may be polygons (triangulated as fans), indices may be
negative, and `v` may carry a vertex color. The MTL is read into glTF's
metallic-roughness terms: Kd and map_Kd are the base color, d (or Tr) its
alpha, Ke and map_Ke the emission, bump/map_Bump/norm the normal map (with
-bm), Ns the roughness (or Pr and Pm from the PBR extension), and illum 0
draws the color unlit. Textures are read relative to the MTL file; a texture
file that is missing leaves the material untextured. OBJ texture coordinates
count v from the bottom; they are flipped to glTF's top-down convention.

### obj_parse

```eskiu
Result<Gltf, string> obj_parse(string text, string base_dir)
```

Parses OBJ text held in memory (NUL-terminated). The MTL files and textures
it names are read relative to base_dir (null for the current directory).

### obj_load

```eskiu
Result<Gltf, string> obj_load(string path)
```

Reads an OBJ file and parses it with obj_parse, reading its MTL files and textures
relative to the file's directory. Errors start with "obj: " and give the line for a
malformed face, vertex, texture coordinate or normal. The caller frees the result with
free().


## `<gpu/render>`

Textures, render pipelines, passes and window surfaces
(imported by `<gpu>`).

A frame is a pass over a target view: a texture's (GpuTexture.view) or a
window surface's (GpuFrame.view, from GpuSurface_frame):

```eskiu
GpuPass pass = gpu.pass(frame.view, GpuColor{0.1, 0.1, 0.1, 1.0}, &depth);
pass.draw(&pipeline, &vertices, 3, 1);
pass.end()?;
surface.present(&frame);
```

Bindings set on a pipeline with bind(), bind_texture() and bind_sampler()
apply to group 0 of its shaders; the bind group they make is kept by the
pipeline and reused until a binding changes. For several groups, or groups
shared by pipelines, describe each with a GpuBindLayout, list them in
GpuPipelineDesc.groups, and set GpuBindGroups on the pass:

```eskiu
GpuBindLayout scene = gpu.bind_layout();
scene.uniform(0, WGPUShaderStage_Vertex);
GpuBindGroup sg = scene.group()?;
sg.buffer(0, &camera);
pass.set_group(0, &sg);
```

Several passes go into one submission through a GpuEncoder:

```eskiu
GpuEncoder enc = gpu.encoder();
GpuPass scene = enc.pass(frame.view, clear, &depth);
...
scene.end()?;
GpuPassOptions keep = GpuPassOptions{load: true};
GpuPass ui = enc.pass_with(frame.view, &keep);
...
ui.end()?;
enc.submit()?;
```

Gpu_texture_with makes 2D-array and cube textures (with mip levels and extra
view formats); a GpuTextureView of one layer (face) and mip level is a
render target, and the texture's own view samples the whole texture.
GpuPipelineDesc.targets and GpuPassOptions.colors draw into up to 8 color
targets at once.

### GpuColor

```eskiu
type GpuColor = WGPUColor;
```

A color as four doubles r, g, b, a (a pass's clear color, the blend constant). A clear
color for an sRGB target is in linear light and the GPU encodes it; for other formats
it is stored as given.

### GpuTexture

```eskiu

    Gpu gpu;
    WGPUTexture handle;
    WGPUTextureView view;
    WGPUTextureFormat format;
    uint32 width;
    uint32 height;
    uint32 mips;
    uint32 samples;
    uint32 layers;
    WGPUTextureViewDimension dimension;
    WGPUTextureUsage usage;
}
```

A texture and its view of the whole of it: a 2D view, a 2D-array view
(layers > 1), or a cube view (dimension Cube, layers 6). layers 0 is 1.

### GpuTextureDesc

```eskiu
struct GpuTextureDesc {
    uint32 width;
    uint32 height;
    WGPUTextureFormat format;
    uint32 layers;
    bool cube;
    bool array;
    uint32 mips;
    bool mipmaps;
    WGPUTextureUsage usage;
    uint32 samples;
    *WGPUTextureFormat view_formats;
    uint32 view_format_count;
}
```

A texture's description for Gpu_texture_with. The zero value of each field:
- format: RGBA8Unorm.
- layers: 1 (6 with cube); more than 1 makes a 2D array, and array makes
  one with a single layer (a shadow map array of one).
- cube: square faces in 6 layers (+X, -X, +Y, -Y, +Z, -Z), sampled as a
  texture_cube; a multiple of 6 layers is a cube array.
- mips: 1 level; mipmaps: the full chain down to 1x1 (mips is then ignored),
  filled with write_level or generate_mips.
- usage: TextureBinding, CopySrc and CopyDst, plus RenderAttachment for the
  formats that can be render targets (depth formats: RenderAttachment and
  TextureBinding; block-compressed: TextureBinding and CopyDst).
- samples: 1.
- view_formats lists the other formats views may have (view_as): the sRGB
  or linear twin of format.

```eskiu
}
```

A view of part of a texture, or of all of it in another format or

### GpuSamplerOptions

### GpuBlend


all source, 0.0 keeps the target.

### GpuStencilFace

```eskiu
    int32 depth_bias;
    float depth_bias_slope;
    GpuStencilFace stencil_front;
    GpuStencilFace stencil_back;
    uint32 stencil_read_mask;
    uint32 stencil_write_mask;
    uint32 samples;
    *GpuColorTarget targets;
    uint32 target_count;
}
```

A render pipeline's description. The zero value of each field is the
common case:
- layout is the one vertex buffer; layouts and layout_count list several
  (up to 8, bound with GpuPass_set_vertices; layouts wins when both are set).
- groups and group_count list the bind group layouts, one per @group index;
  without them the pipeline takes its layout from the shader and binds group
  0 with bind(), bind_texture() and bind_sampler().
- blend: true is GPU_BLEND_ALPHA; blend_mode picks a preset and blend_state,
  when not null, is any WGPUBlendState. no_color_write leaves the color
  target untouched (a depth-only draw).
- depth turns on the depth test against a depth_format texture (default
  Depth24Plus, also Depth32Float) with depth_compare (default Less);
  depth_read_only turns depth writes off. depth_bias and depth_bias_slope
  offset the depth written.
- stencil_front and stencil_back test and update the stencil of a
  depth_format with one (Depth24PlusStencil8, Depth32FloatStencil8 when
  Gpu.depth32_stencil8, Stencil8) against the pass's reference
  (GpuPass_set_stencil_reference); stencil_back left zero is stencil_front.
  stencil_read_mask and stencil_write_mask are 0xFF when 0 (a mask of 0 is
  the same as an Always or Never compare, or Keep ops). The stencil, like
  the depth, needs depth: a stencil-only draw sets depth_compare Always and
  depth_read_only.
- samples is the multisample count, 1 or 4 (0 is 1); the pass's attachments
  must have the same count (Gpu_target_msaa).
- targets and target_count list several color targets, written by the
  fragment shader's @location(0) to @location(7) (up to 8, at most 32 bytes
  per pixel in all); format and the blend fields then do nothing. The pass
  needs the same formats in the same order (GpuPassOptions.colors).
- fragment null makes a pipeline with no fragment stage and no color target,
  which only writes depth (a shadow map), drawn in a pass without colors.

### GpuPassOptions

```eskiu
struct GpuPassOptions {
    GpuColor clear;
    bool load;
    *GpuTexture depth;
    bool depth_load;
    uint32 stencil_clear;
    bool stencil_load;
    WGPUTextureView resolve;
    bool discard;
    *GpuColorAttachment colors;
    uint32 color_count;

}
```

A pass's attachments: the color target is cleared to clear, or keeps its
pixels with load; the depth texture, when given, is cleared to 1.0, or keeps
its values with depth_load. When the depth texture's format has a stencil,
the stencil is cleared to stencil_clear, or kept with stencil_load.
A multisampled target (Gpu_target_msaa) is resolved at the end of the pass
into resolve, a single-sample view of the same format and size (a surface
frame's view or a target's); discard then drops the multisampled pixels
instead of storing them, which saves memory traffic on tile GPUs (phones)
when no later pass loads them.
colors and color_count list several color attachments (up to 8), each
with its own clear, load, resolve and discard; the pass's target argument is
then null and clear, load, resolve and discard here do nothing. A null
target with no colors is a pass with only the depth attachment.
depth_view, when set, is the depth attachment instead of depth: one layer of
a depth texture array (GpuTexture_view_level), such as one shadow map.

## `<gpu/safetensors>`

The safetensors format (Hugging Face): read and write.

A file is an 8-byte little-endian header size, a JSON header mapping each
tensor name to its dtype, shape and byte range, then the raw data.

```eskiu
Safetensors st = safetensors_load("model.safetensors")?;
defer st.free();
SafeTensor* w = st.tensor("model.embed_tokens.weight");
*float v = alloc<float>((int64)w.count);
w.floats(v);

SafetensorsWriter out;
out.add("w1", w1_data, 784, 128);
out.save("mnist.safetensors")?;
```

### SafeTensor

```eskiu
struct SafeTensor {
    String name;
    String dtype;
    int ndims;
    uint64[8] shape;
    uint64 count;
    *uint8 data;
    uint64 size;
}
```

One tensor of a file: dtype as the file names it ("F32", "F16", "BF16", "I8"...), shape
the ndims dimensions with the slowest-varying first (row-major), count the number of
values, and data the size bytes of raw little-endian values inside the file.

### Safetensors

```eskiu
struct Safetensors {
    *uint8 file;
    uint64 len;
    List<SafeTensor> tensors;
}
```

A loaded safetensors file: file is the whole file in memory (len bytes) and tensors its
tensors in header order, whose data pointers point into file. The __metadata__ entry is
skipped.

### SafetensorsWriter

```eskiu
struct SafetensorsWriter {
    List<_SafeEntry> entries;
}
```

Tensors to save, kept by reference: the data must live until save().

### safetensors_dtype_size

```eskiu
int safetensors_dtype_size(string d)
```

Bytes per element of a dtype; 0 when unknown.

### safetensors_load

```eskiu
Result<Safetensors, string> safetensors_load(string path)
```

Reads the file at path and parses it with safetensors_parse. Errors start with
"safetensors: ": the file cannot be read, its header is not a JSON object, or a tensor
has an unknown dtype, a bad shape, or a byte range that is outside the file or does not
match its shape.

### safetensors_parse

```eskiu
Result<Safetensors, string> safetensors_parse(*uint8 data, uint64 len)
```

Parses a file held in memory; the Safetensors owns data from then on.

### Safetensors_tensor

```eskiu
SafeTensor* Safetensors_tensor(*Safetensors self, string name)
```

The tensor called name, or null when there is none. The pointer lives as long as the
Safetensors.

### SafeTensor_floats

```eskiu
bool SafeTensor_floats(SafeTensor* self, *float out)
```

The tensor's values as floats (out holds count values); false when the
dtype is not a floating point one.

### Safetensors_free_entries

```eskiu

```

Frees the tensor table but not the file bytes (file), which the caller then owns.

### Safetensors_free

```eskiu
void Safetensors_free(*Safetensors self)
```

Frees the tensor table and the file bytes; every tensor's data becomes invalid.

### SafetensorsWriter_add

```eskiu

```

Adds an F32 tensor of rows x cols values (cols 0 for a vector of rows).

### SafetensorsWriter_save

```eskiu

```

Writes the added tensors to path as F32, in the order they were added, with the header

## `<gpu/touch>`

Touches on a GpuView (`<gpu/ui>`) and the set of fingers that are down.

`<gpu/ui>`'s use_gpu_touch calls a handler with each GpuTouch; use_gpu_touches keeps a
GpuTouches up to date for a game to read once per frame:

```eskiu
*GpuTouches touches = use_gpu_touches();
use_frame(true, void(Tick t) {
    for (i in 0..touches.down.size) { GpuTouchPoint p = touches.down.data[i]; ... }
    for (i in 0..touches.released.size) { ... }   // went up since the last frame
    touches.end_frame();
});
```

This module has no `<ui>` dependency: it is the part of `<gpu/ui>` that runs anywhere.

### GPU_TOUCH_DOWN, GPU_TOUCH_MOVE, GPU_TOUCH_UP, GPU_TOUCH_CANCEL

```eskiu
const int GPU_TOUCH_DOWN = 0;
const int GPU_TOUCH_MOVE = 1;
const int GPU_TOUCH_UP = 2;
const int GPU_TOUCH_CANCEL = 3;
```

A touch's phase: a finger went down, moved, went up, or was cancelled by the system (the
gesture was taken over or the view went away).

### GpuTouch

```eskiu
struct GpuTouch {
    int id;
    int phase;
    float x;
    float y;
    double time;
}
```

One finger's change. id stays the same from GPU_TOUCH_DOWN to its GPU_TOUCH_UP or
GPU_TOUCH_CANCEL, and is reused by a later finger after that (Android's pointer ids;
on iOS the smallest id not in use). x and y are pixels from the GpuView's top left, the
units of use_gpu_surface's size; time is seconds on the platform's event clock.

### GpuTouchPoint

```eskiu
struct GpuTouchPoint {
    int id;
    int phase;
    float x;
    float y;
    float start_x;
    float start_y;
    double start_time;
    double time;
    bool began;
}
```

A finger as GpuTouches tracks it: where it is, where and when it went down, and phase,
the last change (GPU_TOUCH_DOWN or GPU_TOUCH_MOVE while down, GPU_TOUCH_UP or
GPU_TOUCH_CANCEL once released). began is true until the end_frame after it went down,
so a tap that goes down and up between two frames is still seen.

### GpuTouches

```eskiu
struct GpuTouches {
    List<GpuTouchPoint> down;
    List<GpuTouchPoint> released;
}
```

The fingers that are down, in the order they went down, and those released since the
last end_frame.

### GpuTouches_apply

```eskiu
void GpuTouches_apply(*GpuTouches self, GpuTouch t)
```

Applies one touch. A down for an id already down releases the old finger as cancelled
first (its up was lost); a move, up or cancel for an id that is not down is ignored.

### GpuTouches_find

```eskiu
*GpuTouchPoint GpuTouches_find(*GpuTouches self, int id)
```

The finger with this id while it is down, else null. The pointer is good until the next
apply.

### GpuTouches_count

```eskiu
int GpuTouches_count(*GpuTouches self)
```

The number of fingers that are down.

### GpuTouches_end_frame

```eskiu
void GpuTouches_end_frame(*GpuTouches self)
```

Ends a frame: forgets the released fingers and clears began.

### GpuTouches_cancel_all

```eskiu
void GpuTouches_cancel_all(*GpuTouches self, double time)
```

Releases every finger as cancelled (the surface went away, the screen changed).

### GpuTouches_free

```eskiu
void GpuTouches_free(*GpuTouches self)
```

Frees both lists.

### gpu_touch_parse

```eskiu
int gpu_touch_parse(string payload, *GpuTouch out, int max)
```

Parses the "gpu" channel's "touch TIME_MS COUNT (ID PHASE X Y)..." into out, at most
max touches. Returns how many, or -1 when the payload is not a well-formed touch event.


## `<gpu/train>`

Training on the GPU with reverse-mode automatic differentiation.

A graph is declared once: parameters, inputs and the operations between
them. backward() appends the gradient of every operation in reverse order,
and an optimizer appends its update, so one run() is a whole training step
in a single compute pass:

```eskiu
NnGraph g = gpu.nn_graph(batch)?;
NnVar x = g.input(784);
NnVar labels = g.labels();
NnVar w = g.param(784, 10, 0.05);
NnVar loss = g.cross_entropy(g.bias(g.matmul(x, w), g.param(1, 10, 0.0)), labels);
g.backward(loss)?;
g.adam(0.001);
...each step:
g.set_input(x, images);
g.set_labels(labels, digits);
g.run()?;
float l = g.read_scalar(loss)?;
```

Every value is a matrix of rows x cols floats, row-major; inputs and the
activations derived from them have one row per example in the batch.
forward() runs only the forward pass, for evaluation.

### NnVar

```eskiu
struct NnVar {
    int id;
}
```

A value in a graph (an index into it).

### NnGraph

```eskiu
struct NnGraph {
    Gpu gpu;
    uint32 batch;
    List<_NnNode> nodes;
    NnProgram fwd;
    NnProgram step;
    NnTensor scratch;
    bool built;
    uint32 adam_t;
    GpuBuffer adam_params;
    uint64 seed;
}
```

A training graph, made by Gpu_nn_graph. batch is the number of examples per step; nodes
are the values in declaration order (an NnVar is an index into it). fwd is the forward-
only program and step the training program, both recorded by backward(); adam_t counts
the steps run, for Adam's bias correction, and seed drives the parameters' random
initialization. It keeps a copy of the Gpu that made it.

### Gpu_nn_graph

```eskiu
Result<NnGraph, string> Gpu_nn_graph(*Gpu self, uint32 batch)
```

An empty graph for batches of batch examples. Declare its values, then call backward()
and an optimizer before the first run().

### NnGraph_input

```eskiu
NnVar NnGraph_input(*NnGraph self, uint32 cols)
```

An input of batch rows and cols columns, filled with set_input.

### NnGraph_labels

```eskiu
NnVar NnGraph_labels(*NnGraph self)
```

The class index of each example (batch values, as floats), for
cross_entropy.

### NnGraph_param

```eskiu
NnVar NnGraph_param(*NnGraph self, uint32 rows, uint32 cols, float scale)
```

A trainable rows x cols parameter, initialized with a normal distribution
of standard deviation scale (0 for zeros).

### NnGraph_set_param

```eskiu
void NnGraph_set_param(*NnGraph self, NnVar p, *float data)
```

Sets the parameter's values from rows * cols floats.

### NnGraph_matmul

```eskiu
NnVar NnGraph_matmul(*NnGraph self, NnVar a, NnVar b)
```

a (r x k) times b (k x c).

### NnGraph_bias

```eskiu
NnVar NnGraph_bias(*NnGraph self, NnVar a, NnVar b)
```

a plus the row vector b (1 x cols) added to every row.

### NnGraph_relu

```eskiu
NnVar NnGraph_relu(*NnGraph self, NnVar a)
```

max(a, 0), element-wise; same shape as a.

### NnGraph_tanh

```eskiu
NnVar NnGraph_tanh(*NnGraph self, NnVar a)
```

tanh(a), element-wise; same shape as a.

### NnGraph_cross_entropy

```eskiu
NnVar NnGraph_cross_entropy(*NnGraph self, NnVar logits, NnVar labels)
```

The mean over the batch of the softmax cross-entropy of logits (one row of
class scores per example) against labels. A 1 x 1 value.

### NnGraph_mse

```eskiu
NnVar NnGraph_mse(*NnGraph self, NnVar a, NnVar target)
```

The mean squared error between a and target (same shape). A 1 x 1 value.

### NnGraph_value

```eskiu
*NnTensor NnGraph_value(*NnGraph self, NnVar v)
```

The node's value tensor (to read activations, or to use it with `<gpu/nn>`).

### NnGraph_set_input

```eskiu
void NnGraph_set_input(*NnGraph self, NnVar v, *float data)
```

Sets the value of input v from batch * cols floats at data (row-major, one row per
example), for the next run.

### NnGraph_set_labels

```eskiu
void NnGraph_set_labels(*NnGraph self, NnVar v, *int classes)
```

Sets labels v from batch class indices at classes (stored as floats), for the next run.

### NnGraph_read

```eskiu
Result<int, string> NnGraph_read(*NnGraph self, NnVar v, *float out)
```

Copies the value of v (rows x cols floats) to out.

### NnGraph_read_scalar

```eskiu
Result<float, string> NnGraph_read_scalar(*NnGraph self, NnVar v)
```

The first value of v (the loss, for a 1 x 1 value), after the work submitted so far has
finished.

### NnGraph_backward

```eskiu
Result<int, string> NnGraph_backward(*NnGraph self, NnVar loss)
```

Records the forward pass and, for loss, the backward pass: the training
program then computes every parameter's gradient. The forward program
(forward()) is recorded as well, for evaluation.

### NnGraph_adam

```eskiu
void NnGraph_adam(*NnGraph self, float lr)
```

Appends an Adam update of every parameter (beta1 0.9, beta2 0.999).

### NnGraph_adam_with

```eskiu
void NnGraph_adam_with(*NnGraph self, float lr, float beta1, float beta2, float weight_decay)
```

Appends an Adam update of every parameter with learning rate lr, the given betas and an
L2 weight decay (weight_decay times the parameter added to its gradient; 0 for none).
Call it once, after backward().

### NnGraph_sgd

```eskiu
void NnGraph_sgd(*NnGraph self, float lr)
```

Appends a plain gradient descent update of every parameter.

### NnGraph_run

```eskiu
Result<int, string> NnGraph_run(*NnGraph self)
```

One training step: forward, backward and the optimizer update.

### NnGraph_forward

```eskiu
Result<int, string> NnGraph_forward(*NnGraph self)
```

The forward pass only (no gradients, no update), for evaluation.

### NnGraph_release

```eskiu
void NnGraph_release(*NnGraph self)
```

Releases both programs and every value, gradient and optimizer tensor of the graph.

## `<gpu/window>`

Windows and input over SDL3, with a GPU surface to draw into: keyboard,
mouse, gamepads and touch. A program that imports it links SDL3; `<gpu>` alone does not.

```eskiu
Window win = window_open("demo", 800, 600)?;
defer win.release();
GpuSurface surface = win.surface(&gpu)?;
WindowEvent ev;
while (running) {
    while (win.poll(&ev)) {
        if (ev.kind == WINDOW_QUIT) running = false;
        if (ev.kind == WINDOW_RESIZE) surface.configure(ev.width, ev.height);
    }
    ...
}
```

Gamepads come as WINDOW_PAD_* events and as a PadState to read once per frame
(Window_pad_state); fingers on a touch screen or a pen come as WINDOW_TOUCH events with a
GpuTouch, as on a mobile GpuView, and Window_set_mouse_touch turns the left mouse button
into a finger too.

In a browser (wasm32-unknown-emscripten) the window is the page's canvas with id
"canvas": the same program builds for both, and the events come from the page. Gamepads
and fingers are desktop only there: no pad is ever connected and no WINDOW_TOUCH comes,
except from the mouse with Window_set_mouse_touch.

```eskiu
    float dx;
    float dy;
    uint32 width;
    uint32 height;
    int pad;
    int axis;
    float value;
    GpuTouch touch;
    bool from_touch;
}
```

One input event. key and repeat are set for key events, button for mouse
buttons (1 left, 2 middle, 3 right) and gamepad buttons (a PAD_ constant), x and y for
mouse and touch events (pixels from the drawable's top left) and the wheel (scroll
amounts), dx and dy for mouse motion (pixels), width and height (pixels) for
WINDOW_RESIZE. pad is the gamepad's id for WINDOW_PAD_ events, stable while it stays
connected; axis and value (from -1 to 1, or 0 to 1 for a trigger, with no deadzone) are
set for WINDOW_PAD_AXIS. touch is the finger of a WINDOW_TOUCH, to hand to
GpuTouches_apply. from_touch marks the mouse events the system makes from a finger on a
touch screen, which come along with its WINDOW_TOUCH events. In a browser, a key that is
neither printable nor a KEY_ constant is 0x40000000 plus its DOM keyCode, and WINDOW_QUIT
never comes.

### window_open

```eskiu
Result<Window, string> window_open(string title, int width, int height)
```

Opens a resizable, high-density window of width x height points (the drawable size in
pixels may be larger: Window_size). It starts SDL's video and gamepad systems first; the
pads connected then come as WINDOW_PAD_ADDED events. Fails with SDL's error message. In a browser it sets the page title and the canvas's CSS size to width x
height (0 x 0 keeps the size the page gives it) and listens to the page's events.

### Window_release

```eskiu
void Window_release(*Window self)
```

Destroys the window, closes its gamepads and shuts SDL down, so a program has one window
at a time. Release the window's GpuSurface first. In a browser it removes the page's event listeners set
through Emscripten's html5 API.

### Window_set_title

```eskiu
void Window_set_title(*Window self, string title)
```

Sets the title shown in the window's title bar (UTF-8).

### Window_size

```eskiu
void Window_size(*Window self, *uint32 width, *uint32 height)
```

The drawable size in pixels (larger than the window's size in points on a
high-density display).

### window_ticks

```eskiu
uint64 window_ticks()
```

Milliseconds since the window system started.

### Window_poll

```eskiu
bool Window_poll(*Window self, *WindowEvent ev)
```

Takes the next pending event into ev; false when there is none. Events the
layer does not describe are skipped.

### Window_set_mouse_touch

```eskiu
void Window_set_mouse_touch(*Window self, bool on)
```

Turns mouse touch on or off. While it is on, a press of the left mouse button, the
motion while it is held and its release come as a WINDOW_TOUCH finger instead of mouse
events, for testing a touch interface on the desktop; the motion with no button held,
the other buttons and the wheel stay mouse events. Fingers on a touch screen are
WINDOW_TOUCH events either way.

### Window_set_pad_deadzone

```eskiu
void Window_set_pad_deadzone(*Window self, float deadzone)
```

Sets the gamepad deadzone, from 0 to 0.9 (0.1 to start with): Window_pad_state reads a
stick as centered while it is within this distance of the center, and a trigger as
released below it, and stretches the rest to the full range. WINDOW_PAD_AXIS values
have no deadzone.

### Window_pad_count

```eskiu

```

The number of connected gamepads.

### Window_pad_id


The id of the connected gamepad at index (0 to Window_pad_count - 1), in the order they
were connected, or -1.

### Window_pad_name

```eskiu
string Window_pad_name(*Window self, int pad)
```

The gamepad's name ("Xbox Series X Controller", "PS5 Controller"), or null when it is not
connected.

### Window_pad_state

```eskiu
bool Window_pad_state(*Window self, int pad, *PadState out)
```

Reads a gamepad as it is now into out, with the deadzone applied. pad is a pad's id, or
PAD_ANY for every connected pad together: a button is held when it is held on any pad,
and each axis is the one farthest from rest. False (and out cleared) when the pad is not
connected, or with PAD_ANY when none is. The state is that of the last Window_poll.

### Window_pad_rumble


Rumbles a gamepad (or every pad, with PAD_ANY) for ms milliseconds: low is the strength
of the low-frequency (left) motor and high of the high-frequency (right) one, from 0 to
1; a new call replaces the last, and 0, 0 stops it. False when no pad that was asked for
can rumble.

## `<gpu/yuv>`

Camera and video frames on the GPU (`<gpu/yuv>`).

A GpuYuv uploads a frame's planes as they are (the luma plane as an R8
texture, an interleaved chroma plane as RG8, separate U and V planes as R8,
each with the frame's row stride) and turns them into RGB in a shader, with
the frame's matrix (BT.601 or BT.709) and range (full or limited). It draws
the picture into a render pass, turned upright and fitted to a rectangle,
or renders it into an RGBA texture of its own.

```eskiu
GpuYuv yuv = gpu.yuv(surface.format)?;
defer yuv.release();
...
yuv.upload((*GpuYuvImage)frame)?;       // a CameraFrame or a VideoFrame
GpuPass pass = gpu.pass(out.view, GpuColor{0.0, 0.0, 0.0, 1.0}, null);
GpuYuvDraw d = GpuYuvDraw{width: 1080.0, height: 1920.0, fit: GPU_YUV_COVER};
yuv.draw(&pass, &d);
pass.end()?;
```

GpuYuvImage has the field layout of eskiu-lang/ui-camera's CameraFrame and
eskiu-lang/video's VideoFrame, so a pointer to either is a pointer to one.

### GpuYuvFormat

```eskiu
enum GpuYuvFormat { GPU_YUV_NV12, GPU_YUV_NV21, GPU_YUV_I420, GPU_YUV_420, GPU_YUV_RGBA }
```

How a frame's pixels are laid out (the values of CameraFormat and
VideoFormat). NV12: a Y plane, then one plane of interleaved U and V (U
first). NV21: the same with V first. I420: Y, U and V planes, chroma a
quarter of the size. GPU_YUV_420: Y, U and V planes whose chroma samples are
pixel_stride bytes apart. RGBA: one plane of 4 bytes a pixel.

### GpuYuvMatrix

```eskiu
enum GpuYuvMatrix { GPU_YUV_BT601, GPU_YUV_BT709 }
```

The matrix a frame's YUV is encoded with: BT.601 (standard definition,
JPEG, phone cameras) or BT.709 (HD video).

### GpuYuvPlane

```eskiu
struct GpuYuvPlane {
    *uint8 data;
    int row_stride;
    int pixel_stride;
    int64 size;
}
```

One plane of a frame: data, the bytes from one row to the next, from one
sample to the next in a row (2 in an interleaved chroma plane, from one U to
the next), and the bytes readable from data.

### GpuYuvImage

```eskiu
struct GpuYuvImage {
    int width;
    int height;
    int format;
    int plane_count;
    GpuYuvPlane[3] planes;
    int rotation;
    int64 timestamp_ns;
    bool front;
    int matrix;
    bool full_range;
}
```

A frame to upload, laid out like CameraFrame and VideoFrame. width and
height are in pixels; plane_count planes are set, as format (a
GpuYuvFormat) says; chroma planes are half the width and height, rounded
up. rotation (0, 90, 180 or 270) is how far to turn it clockwise to be
upright; matrix (a GpuYuvMatrix) and full_range say how its YUV maps to RGB.
timestamp_ns and front are not used here.

### GpuYuvFit

```eskiu
enum GpuYuvFit { GPU_YUV_STRETCH, GPU_YUV_CONTAIN, GPU_YUV_COVER }
```

How GpuYuv_draw fits the picture in its rectangle. STRETCH fills it,
CONTAIN shows the whole picture at its aspect ratio (the rest of the
rectangle keeps what the pass has), COVER fills it at the picture's aspect
ratio and crops what overflows.

### GpuYuvDraw

```eskiu
struct GpuYuvDraw {
    float x;
    float y;
    float width;
    float height;
    GpuYuvFit fit;
    bool upright = true;
    bool mirror;
    bool nearest;
}
```

Where and how GpuYuv_draw draws: the rectangle of the target in pixels from
the top left (x, y, width, height; it must lie inside the target), the fit,
whether to turn the picture by the frame's rotation (upright), to mirror it
left to right after turning (mirror, the way a front camera's preview is
shown), and to take the nearest texel instead of filtering (nearest).

### GpuYuv

```eskiu
struct GpuYuv {
    Gpu gpu;
    WGPUTextureFormat target_format;
    GpuTexture[3] planes;
    GpuTexture blank;
    GpuSampler sampler;
    GpuPipeline pipe;
    GpuPipeline rgba_pipe;
    GpuPipeline depth_pipe;
    WGPUTextureFormat depth_pipe_format;
    GpuBuffer uniforms;
    GpuBuffer rgba_uniforms;
    GpuTexture rgba;
    *uint8 scratch;
    int64 scratch_size;
    int width;
    int height;
    int format;
    int rotation;
    int matrix;
    bool full_range;
    bool chroma_swap;
    bool loaded;
}
```

A frame uploader and converter made by Gpu_yuv; release it with release().
After upload, width, height, format and rotation are the frame's; rgba is
the texture GpuYuv_to_rgba renders into. The plane textures, pipelines and
buffers are kept from one frame to the next and made again only when the
frame's size or layout changes.

### Gpu_yuv

```eskiu
Result<GpuYuv, string> Gpu_yuv(*Gpu self, WGPUTextureFormat target_format)
```

A GpuYuv that draws into targets of target_format (a surface's format, or
RGBA8Unorm when 0). An sRGB target gets the picture's colors as they are:
the shader decodes them to linear light so the target's encoding gives them
back.

### gpu_yuv_check

```eskiu
string gpu_yuv_check(*GpuYuvImage image)
```

Checks that image describes a frame whose planes cover its pixels: a known
format, the plane count it needs, strides and sizes that keep every read
inside the planes. Returns null when it does, else what is wrong.

### GpuYuv_upload

```eskiu
Result<int, string> GpuYuv_upload(*GpuYuv self, *GpuYuvImage image)
```

Uploads a frame's planes (checked first with gpu_yuv_check), ready for draw
and to_rgba. The planes are read during the call only: a borrowed camera or
video frame can be given back once it returns.

### GpuYuv_out_width

```eskiu
int GpuYuv_out_width(*GpuYuv self, bool upright)
```

The uploaded frame's width once turned upright (its height when the
rotation is 90 or 270), or as it is.

### GpuYuv_out_height

```eskiu
int GpuYuv_out_height(*GpuYuv self, bool upright)
```

The uploaded frame's height once turned upright, or as it is.

### GpuYuv_draw

```eskiu
void GpuYuv_draw(*GpuYuv self, *GpuPass pass, *GpuYuvDraw d)
```

Draws the uploaded frame into pass (whose target has the GpuYuv's
target_format) in d's rectangle, fitted, turned and mirrored as d says. It
sets the pass's viewport to the rectangle it covers, which stays for the
draws that follow. The uniforms are written to the queue, so one GpuYuv
draws once per submission (a second draw in the same one overrides the
first's placement); use a GpuYuv per picture for several.

### GpuYuv_to_rgba

```eskiu
Result<*GpuTexture, string> GpuYuv_to_rgba(*GpuYuv self, bool upright)
```

Renders the uploaded frame into the GpuYuv's own RGBA8Unorm texture
(self.rgba, made again when the size changes) and returns it: turned upright
when upright, one texel per pixel (no filtering, chroma from the sample that
covers each pixel), ready to sample, read back (GpuTexture_read) or hand to
a model. The texture stays the GpuYuv's: release the GpuYuv, not it.

### GpuYuv_release

```eskiu
void GpuYuv_release(*GpuYuv self)
```

Releases the textures, pipelines, buffers and scratch memory; a second call
does nothing.
